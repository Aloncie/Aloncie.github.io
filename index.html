Youtube agent

Youtube agent is a personal tool. I use it to read the analytics of my own YouTube channel, so I can check the numbers I collect from YouTube Studio.

It asks Google for read-only access through the YouTube Data API and the YouTube Analytics API. It can't upload, change or delete anything. It's not a public service: only I use it, with my own Google account.
